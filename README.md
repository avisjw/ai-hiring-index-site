# AI Hiring Index

Open AI roles pulled straight from company hiring systems, sorted by how much
technical background each one actually needs.

- **[index.html](index.html)** — the board. Search and filter 3,000+ open AI roles
  across three tracks: no technical background, some technical skills, strong
  technical background.
- **[brief.html](brief.html)** — weekly read of the AI hiring market: stack demand,
  who is scaling, reqs that won't close, published salary bands.
- **[linkedin.html](linkedin.html)** — pre-built LinkedIn searches with adjustable
  time windows.

Every role links to the employer's own posting. No reposts, no staffing-agency
spam, no scraped listings.

Built from the public Greenhouse, Lever, Ashby, SmartRecruiters, Workable and
Recruitee APIs — the same endpoints that render each company's careers page.

This repository holds the published pages only; it is generated output.
